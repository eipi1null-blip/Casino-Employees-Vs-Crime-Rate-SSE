# Casino Employees & Crime Rate — Residual Explorer

A dependency-free interactive web app based on the GeoGebra “Sum of Square Residuals” activity, using the casino employee and crime-rate dataset from Table 3.5.

## Run locally

Open `index.html` directly, or serve this folder with any static web server.

## Deploy with GitHub Pages

1. Create a GitHub repository and add the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

No build step, package manager, or API key is required.

## Dataset

- x: number of casino employees, in thousands
- y: crime rate, number of crimes per 1,000 population
- years: 2000–2009
